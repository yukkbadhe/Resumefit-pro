# ATS Resume Checker

An AI-powered web application that analyzes resumes against job descriptions and calculates an ATS compatibility score. It helps users optimize their resumes for better job matching.

---

## 🚀 Features

- Resume keyword matching
- Missing keyword detection
- ATS score calculation
- Resume section analysis
- Role prediction
- Personalized suggestions for improvement
- Dark / Light mode support
- Resume text input support

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript

---

## ⚙️ How It Works

1. Paste your resume text  
2. Paste the job description  
3. Click **Analyze**  
4. Get instant results:
   - ATS Score  
   - Matched Keywords  
   - Missing Keywords  
   - Improvement Suggestions
